# multiswitcher — динамичная сцена

10 секунд · 1920 × 1080 · 60 fps · 600 кадров. весь экранный текст строчный, включая `option`, `mac` и `sokolovmo/multiswitcher`.

готовые записанные звуки уже лежат в `public/audio`. для рендера не нужны ключи openverse, earshot или внешние аудиосервисы.

```sh
npm ci
npm run dev -- --port=4180
```

композиция: [multiswitcher](http://localhost:4180/multiswitcher).

```sh
npm run lint
npm run render
```

экспорт создаст `out/multiswitcher.mp4`. финальный mp4 собран и опубликован: [посмотреть на сайте](https://sokolovmo.ru/multiswitcher/#video), [скачать mp4](https://sokolovmo.ru/multiswitcher/multiswitcher-demo.mp4). готовый файл также хранится в [release-site](../../release-site/multiswitcher-demo.mp4). рендерер проверен на восьми настоящих контрольных кадрах, включая нажатие, результат, меню и финал. `source-map` для `@remotion/renderer` закреплён на `0.7.6`: установленный пакет `0.8.0` содержал пустой `lib/util.js` и падал при подготовке рендера.

## файлы

- `src/MultiSwitcherScene.tsx` — сцена, spring-анимации, каретка, меню и аудиослой.
- `src/timing.json` — единая таблица кадров для печати, option и монтажа.
- `src/Root.tsx` — параметры композиции.
- `public/audio/sfx-scissor-master.wav` — готовый синхронный мастер. подключён один раз, чтобы не удваивать эффекты.
- `audio-cues.json` — монтажные события и исходные сэмплы. 29 событий, включая 18 букв.
- `audio-sources.json` — авторы, ссылки, условия cc0 и описание обработки каждой записи.
- `review/earshot.json` — реальные измерения мастера и совпадения атак с кадрами.

## что изменено

- 14 секунд заменены 10 секундами с шестью визуальными планами: ошибка и исправление (0–1.8 с), продолжение (1.8–3.5 с), меню (3.5–5.5 с), выделенный текст (5.5–7 с), приватность (7–8 с), финал (8–10 с).
- spring: stiffness 720, damping 17, mass 0.42; появления укладываются в 10–16 кадров. монтаж — жёсткие смены без длинных затемнений. отдельный двухкадровый нажим клавиши, короткий отскок результата и пружинистое меню.
- печать использует заданные неравномерные интервалы 5–17 кадров, а не случайный таймер. каретка мигает по кадрам, включается при наборе и сбрасывает мигание после option. повторный рендер и перемотка дают те же буквы и звук.
- только системный стек `-apple-system, blinkmacsystemfont, sf pro display, sf pro text`. проверено в [исходном коде системной типографики](../../macos/Sources/MultiSwitcher/SystemTypography.swift): приложение использует системные обычный и моноширинный шрифты. веб-шрифтов, сетевых загрузок шрифтов и satoshi в новой композиции нет. точный нативный шрифт предполагает рендер на macos.
- основа меню — настоящий снимок `design/interface-audit-2026-11-06/final-matrix/native-menu-light.png`; строка раскладки перевёрстана строчными. значок `ая` в строке меню — постановочная строчная версия. исходная иконка `aя` с прописными знаками исключена. это редакторская композиция, не запись текущего состояния установленного приложения.
- ручное исправление последнего слова и выделения опирается на существующие пути `keyboardmonitor` и `textconverter`; приложение не получает выдуманного редактора сообщений. код самого нативного приложения не менялся.

## звук и проверка

в исходном репозитории аудиофайлов не найдено. использована реальная запись низкопрофильной ножничной клавиатуры plummet, пластиковых щелчков и движений предметов из freesound. лицензии cc0 указаны в `audio-sources.json`. нажатие option теперь озвучено отдельным ударом из той же ножничной клавиатуры; это фоли, а не подтверждённая запись конкретной клавиши option. синтез, uisfx, музыка и озвучка не использовались.

`real-sfx` нарезал и свёл записи по таблице кадров; `earshot` проверил метры и обнаруженные атаки. 18 из 18 печатаемых знаков имеют атаку в пределах одного кадра при 60 fps; максимальное отклонение — 6.3 мс. option — 3 мс; клик открытия меню — 2.7 мс. общая медиана абсолютных отклонений — 3 мс. раннее начало свушей намеренное: на монтажный кадр поставлен их пик, а не начало.

мастер: -27.9 lufs, true peak -2.4 dbtp, 0 клиппированных сэмплов. это измерения, не оценка вкуса. семантические модели earshot (~1.1 гб) не загружались, «реальность» и красота не оценивались по модели. происхождение записей подтверждено страницами авторов.

автоматический `real-sfx` critic не выдал общий pass: он отмечает повторяемость интерфейсного фоли и низкую среднюю громкость разреженного микса; детектор пиков также смешивает клик меню с соседним свушем. независимый детектор атак earshot видит клик на 2.7 мс от кадра. не добавляли лишние звуки и не усиливали лимитер только ради балла. отчёты сохранены, эти ограничения не скрыты.

## как пользоваться earshot дальше

установленный скилл содержал инструкции без исполняемого пакета. для этой работы пакет `leonxlnx/earshot`, версия `0.4.1`, запущен в отдельном временном окружении. чтобы получить постоянное окружение внутри проекта:

```sh
sh scripts/setup-earshot.sh
.tools/earshot-venv/bin/earshot measure public/audio/sfx-master.wav
```

объективные измерения работают без моделей. для анализа типов звука:

```sh
.tools/earshot-venv/bin/earshot doctor --fetch
.tools/earshot-venv/bin/earshot describe public/audio/option.wav
```

второй режим скачивает модели локально. аудио никуда отправлять не требуется.

openverse не использовался для анонимного поиска: отсутствуют `OPENVERSE_CLIENT_ID` и `OPENVERSE_CLIENT_SECRET`. для него нужно зарегистрировать oauth-клиент и передать эти переменные в окружение. записи в этой версии найдены напрямую на freesound; ключи для рендера не нужны.

## повторная сборка звука

`python3 scripts/fetch-audio.py` восстанавливает исходные записи cc0. `python3 scripts/prepare-audio.py` формирует нарезки, проектный конфиг и cue sheet для установленного `real-sfx`; установленные файлы скилла не меняются. затем `real-sfx/scripts/mix.py work/cues.json --out work/mix.mp4 --target-lufs -18 --ceiling-db -3` с `REAL_SFX_CONFIG`, указывающим на `work/real-sfx-config.json`, создаёт аудиомастер `work/mix_mix.wav`; его нужно скопировать в `public/audio/sfx-master.wav` и `public/audio/sfx-scissor-master.wav`. вызов `scripts/check-audio.py` из окружения earshot обновляет измерения.

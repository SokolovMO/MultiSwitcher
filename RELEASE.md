# Текущий выпуск MultiSwitcher

Самостоятельная раздача: https://sokolovmo.ru/multiswitcher/ .
Инструкция сборки, публикации и возврата: [DISTRIBUTION.md](DISTRIBUTION.md).

Apple Developer, нотарификация, GitHub App, Vercel и панель публикации не требуются.
Используются постоянный локальный сертификат подписи приложения и отдельный ключ
Ed25519 для ZIP/appcast. Установка обновлений — через встроенный Sparkle, после
подтверждения пользователя. Сборка не включает Sentry.

Предыдущая схема и результаты приёмки сохранены в RELEASE-HISTORY.md; старые
workflows перемещены из активной папки в .github/legacy-workflows и не запускаются.
Старые create/prepare/manifest helper-скрипты сохранены для истории, но не вызываются
самостоятельным выпуском. Текущий выпуск не зависит от GitHub Releases/Pages.

Перед полноценным релизом отдельно проверяются физический ввод, Option-конвертация,
отмена, secure input, буфер обмена, профиль, разрешения macOS, установка и обновление
A → B, поддерживаемые приложения и версии macOS. Компиляция и тесты не заменяют
эту приёмку. Не объявлять 1.0 по одному факту публикации ZIP.

# Общий стандарт MultiSwitcher и MultiShift

Это стандарт семейства Multi, согласованный пользователем 13 ноября 2026.
Он задаёт общий вид, сохраняя факты и индивидуальность каждого приложения.
Текущие версии, статусы CI и публикаций проверять заново.

## Язык и структура

- `README.md` — русский; `README.en.md` — английский. Взаимные ссылки справа сверху.
- Старые `README.ru.md` или `docs/README.ru.md` — короткие переходы с сохранением
  опубликованных якорей, если на них есть ссылки. Старый русский URL не должен
  внезапно открывать английскую страницу.
- Сначала picture hero, затем бейджи CI / минимальная macOS / Apple silicon / лицензия,
  затем Скачать / Установка / Помощь / Ошибка. Одинаковая последовательность у обоих.
- Далее: назначение, возможности, реальный screenshot, установка DMG и Homebrew,
  обновления, конфиденциальность, сборка, участие, другие приложения, лицензия/maintainer.
- Переводить подписи, alt и metadata для русского основного README. Не переводить
  собственные названия продукта, флаги CLI и имена инструментов.
- Supporting docs и формы по возможности русские по умолчанию; принимать RU/EN обращения.

## Графика

Активные файлы в `.github/assets/`:

- `header-light.svg`, `header-dark.svg` — русский основной вариант 1280×400.
- `header-light.en.svg`, `header-dark.en.svg` — английский вариант той же геометрии.
- `social-preview.svg`, `social-preview.png` — русская карточка 1280×640, PNG <1 MB.

Шрифт Helvetica/Arial/sans-serif; пример ввода может использовать Menlo/Consolas.
Белый фон #ffffff, основной текст #1f2328, вторичный #59636e,
поверхность #f6f8fa, граница #d1d9e0.
Тёмный фон #0d1117, текст #f0f6fc, вторичный #9198a1,
поверхность #151b23, граница #3d444d.

Умеренная графитовая палитра, без декоративных градиентов и россыпи бейджей.
Верхняя строка: знак 84×84 в x48/y44, имя около x158/y103.
Далее — характерный для приложения пример действия, ниже короткая подпись.
У MultiSwitcher знак AЯ и `ghbdtn → привет`. У MultiShift собственная стрелка
и реальный сценарий работы с копиями файлов. Не переносить знак/функции одного
приложения в другое ради формальной одинаковости.

Реальные скриншоты могут храниться в существующем QA-архиве. Не коммитить
новые полные дампы интерфейса, приватные профили или записи экрана ради README.

## Отличия, которые нужно сохранить

MultiSwitcher: https://github.com/SokolovMO/MultiSwitcher,
сайт https://sokolovmo.ru/multiswitcher/, MIT, arm64, macOS 15+.
Исправление раскладки и текста; глобальные функции требуют Accessibility и Input Monitoring.
Проверять фактическую схему Sparkle, не обещать дельты без доказательств.

MultiShift: https://github.com/SokolovMO/MultiShift,
сайт https://sokolovmo.ru/multishift/, AGPL-3.0, Apple silicon, macOS 14+.
Преобразование файлов и сохранение копий. Дельта-обновления и требования к ним
описаны в его AGENTS.md и документации выпуска; оформление их не меняет.

Оба приложения на момент согласования распространялись самостоятельно без
нотарификации Apple. Проверять это утверждение перед будущими обновлениями текста.
Точные brew-команды, версии, CI workflow и маршруты документации брать из каждого проекта.

## Семейство и сопровождение

Добавить взаимный блок «Другие приложения» / “Other apps”, без ложного общего пакета
или обязательной установки второго приложения. Общий owner — SokolovMO.
Авторство, inherited copyright и лицензии не выравнивать и не удалять.

Исходник скила хранится в `skills/github-app-presentation/` репозитория MultiSwitcher;
пользовательская установка — `~/.codex/skills/github-app-presentation/`.
При изменении стандарта синхронизировать эту установку и оба репозитория в рамках
явного поручения, не запускать бесконечный обмен сообщениями между чатами.

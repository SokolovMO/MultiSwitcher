# Политика безопасности

## Сообщить об уязвимости

Не публикуйте инструкции эксплуатации уязвимости, ключи и личные данные в открытых Issues.
Используйте **Security → Report a vulnerability**:

https://github.com/SokolovMO/MultiSwitcher/security/advisories/new

Если закрытая отправка временно недоступна, свяжитесь с владельцем через профиль
GitHub и сначала запросите частный канал. В начальное публичное сообщение не
включайте подробности эксплуатации и пользовательские данные.

MultiSwitcher обрабатывает клавиатурные события и может изменять текст в других
приложениях. Полезный отчёт содержит версию/сборку, macOS и архитектуру, затронутую
функцию, минимальный вымышленный пример и источник установки. Официальная загрузка:
https://sokolovmo.ru/multiswitcher/.

Не отправляйте пароли, реальные сообщения, буфер обмена, личные профили, закрытые
ключи и необработанные журналы. Приложение не загружает их автоматически.

## Поддерживаемые версии

Сообщайте о проблемах последней сборки с официального сайта. Записи проверок
выпуска описывают проверенные сценарии и оставшиеся ограничения. Текущий независимый
дистрибутив не нотарифицирован Apple. Долгосрочная поддержка безопасности старых
сборок не обещается.

## Сроки ответа

Гарантированных сроков ответа нет. Maintainer оценивает сообщения и распространяет
исправления через проверенные изменения и подписанные выпуски, когда они готовы.

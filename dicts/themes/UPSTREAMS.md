# Curated vocabulary references

MultiSwitcher keeps compact, manually reviewed vocabulary packs. These files are not a live copy of any upstream corpus, and updates are shipped with app releases so keyboard handling never depends on a network request.

The English technology and informal-language lists were reviewed against the CSpell `software-terms` and `en-slang` dictionaries. The CSpell `fonts` package was reviewed as a possible reference, but its word list is not included. The design pack contains locally curated interface and typography terms. The upstream package pages identify MIT licensing: <https://github.com/streetsidesoftware/cspell-dicts/tree/main/dictionaries/software-terms>, <https://github.com/streetsidesoftware/cspell-dicts/tree/main/dictionaries/fonts>, and <https://github.com/streetsidesoftware/cspell-dicts/tree/main/dictionaries/en-slang>. Accessed 2026-10-21.

Only individual spellings were selected and reviewed; no upstream package or bulk list is included. The compiled MultiSwitcher packs remain under the project license in `LICENSE`. Theme files contain accepted spellings only: they do not create replacement rules or normalize slang.

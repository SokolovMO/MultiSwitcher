установка через Homebrew.

если Homebrew уже установлен, откройте «Терминал» и выполните команды ниже. нужен Homebrew 7 или новее и Mac с Apple Silicon.

brew tap SokolovMO/apps
HOMEBREW_MULTI_APPS_ALLOW_UNNOTARIZED=1 brew install --cask SokolovMO/apps/multiswitcher

параметр в команде явно разрешает проверить подпись и снять карантин только с MultiSwitcher. приложение пока без нотарификации Apple; используйте этот способ, если доверяете издателю.

посмотреть tap на GitHub

обновления — внутри приложения

откройте «Настройки → О приложении → Проверить обновления». приложение загрузит новую версию и предложит установить её с перезапуском. обновления через Homebrew остаются запасным ручным способом.

перед первым запуском

если macOS остановит открытие

приложение пока без нотарификации Apple. откройте «Системные настройки → Конфиденциальность и безопасность» и разрешите запуск multiswitcher.

что произойдёт при замене старой версии

перед заменой выйдите из работающего приложения. перетащите новую копию в «Программы» и подтвердите замену в Finder. настройки и результаты хранятся отдельно от приложения. для последующих обновлений используйте встроенную проверку в настройках — ручная замена через Finder не требуется.

какие разрешения нужны

MultiSwitcher нужны «Универсальный доступ» и «Мониторинг ввода». приложение покажет инструкцию; разрешениями управляет macOS. если после обновления доступ сбросился, его нужно выдать снова вручную.

как приходят обновления

приложение проверяет подписанную ленту на нашем сайте. новую версию можно установить после подтверждения; ручная проверка есть в настройках. отдельный аккаунт не нужен.

что остаётся на вашем Mac

анализ текста, словари и профиль работают локально. набранный текст и содержимое буфера не отправляются при проверке обновлений. в этой сборке нет внешней службы отчётов о сбоях.

счётчик сайта хранит только общие числа по приложению, дню и версии. короткоживущие хеши в памяти защищают от повторного счёта; IP и User-Agent не записываются в базу счётчика.
